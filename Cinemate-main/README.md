Cinemate is a **modern movie search web application** built with **React** that allows users to explore and discover movies easily.  
With a clean UI and smooth functionality, Cinemate is perfect for film lovers.

---

## ✨ Features

- 🔍 **Search Movies** – Instantly search for movies by title.
- 📝 **Detailed Information** – View plot, cast, release date, and more.
- 🌟 **Ratings** – Displays IMDb ratings for each movie.
- 📱 **Responsive Design** – Works across devices.
- ⚡ **Fast** – Powered by React for instant UI updates.

## 📦 Installation

To run Cinemate locally:

```bash
# Clone this repository
git clone https://github.com/Omkarjagtap15/Cinemate.git

# Go inside the project folder
cd Cinemate

# Install dependencies
npm install

# Start development server
npm start
